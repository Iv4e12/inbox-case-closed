INBOX: Case Closed
Case 001 - The 9:17 incident
A detective game played entirely through email.

At 9:17, a painting called The Blue Room vanished from the Blackwood Gallery.
You are assigned to the case.
Your job id to examine the evidence, compare statements, question inconcistencies and work out what
actually happened.

# HOW TO PLAY
The game is played through email.
1. Open your email app
2. Send an email to blackwood.detective.offfice@gmail.com containing "START CASE 001"
3. Read the first case file you receive.
4. Investigate the evidence

# Available commands
START CASE 001 Begin game
STATUS Check your progress
HINT Get a hint
HELP View commands

Features
Seven-stage investigation.
Four suspects with different motives and alibis.
Evidence distributed across emails and documents.
Answer evaluation using Gemini.
Individual player progress tracking.
Email-based hints and case progression.
Multiple players can investigate independently.
How It Was Built
The project uses:
Google Apps Script — game logic and automation.
Gmail — the game's interface.
Google Sheets — player progress and processed email tracking.
Gemini API — evaluating player answers.
No traditional game engine is used.
Project Structure
The repository contains the case files, evidence documents, and the source code responsible for processing emails and tracking player progress.
